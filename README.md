# 仮名化マスカー（namemask）

生成 AI にテキストを貼る前に、個人情報などを仮名に置き換え、AI の回答を元の表記に復元するための小さな Web ツールです。

## 使い方

1. 元のテキストを貼り付けて「仮名化する」を押します。
2. メールアドレス、電話番号（日本の形式）、郵便番号、URL が自動検出され、【メール1】【電話1】のような仮名に置き換わります。同じ原文には同じ仮名が付きます。
3. 任意で「ユーザー辞書」（原文 → 仮名のペア）を登録すると、正規表現より先に適用されます。会社名や人名など、パターンで拾えない語の置換に使えます。
4. 「対応表の保存」に名前を入れると、対応表が SQLite に保存されます。
5. AI の回答を受け取ったら、保存済み対応表の「復元に使う」から回答を貼り付けると、仮名が元の表記に戻ります。

DB のパスは環境変数 `NAMEMASK_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- 検出は正規表現による簡易なものです。**人名・会社名・住所そのものは自動では検出できません**（辞書登録で対応してください）。検出漏れがあり得るため、「これで完全に匿名化できた」とは考えないでください。
- 電話番号は `090-1234-5678` のようなハイフン付き形式と、ハイフンなしの 10〜11 桁の数字列を対象にしています。数字列は注文番号など別の数字も拾う可能性があります。
- 対応表には元の個人情報そのものが含まれます。保存した対応表の取り扱いには十分注意してください。
- ログイン機能はありません。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
